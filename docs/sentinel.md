# Provider Sentinel retirement

> **Retired:** Provider Sentinel automation is no longer part of this repository.

This page is retained only as a retirement notice. Embedded Sentinel workflows, schedules, incident dispatch, deployment
credentials, and local verification tooling must not be restored here. This repository does not operate the Provider
Sentinel service.

For the current standalone implementation and its operating instructions, see the
[`ubiquity/sentinel` repository](https://github.com/ubiquity/sentinel).
