Quickstart

Use your gateway token to discover models.

export UOS_AI_TOKEN="..."

curl -sS https://ai.ubq.fi/v1/models \
  -H "Authorization: Bearer $UOS_AI_TOKEN"

Base URL: https://ai.ubq.fi/v1
