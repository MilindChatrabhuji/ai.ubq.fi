About

AI.UBQ.FI is the OpenAI-compatible inference service for approved UbiquityOS workloads.

One gateway

One API for model discovery, Chat Completions, and Responses. Approved applications and agents use GET /v1/models to find supported models.

Start with the developer guide, OpenAPI contract, or agent instructions.

Access

Use a gateway token issued by your operator. Keep it private and respect rate limits. Client tokens are not forwarded upstream. Model availability comes from the gateway catalog, not the public OpenAI catalog.
