Active providers

              

                Check every provider the gateway may dispatch to. Unchecked providers leave inference routing,
                and the models only they serve disappear from /v1/models, the public catalog, and
                the Codex catalog. Each configured Codex subscription is selectable on its own, so the
                subscription tier can be narrowed to one account. The waterfall order itself never changes.
                Saving an empty selection removes the filter, so every provider is active again.

Model Whitelist

              

                Check every model the gateway may advertise on /models, /v1/models, and the
                Codex catalog. Checked models stay listed; unchecked models are hidden while at least one model is

                Inference is never blocked.
