# Observability runtime

Contract v1 ports source `ba5ef05e74e7684589981c9b2a22518137a964f1` into the one `QueryStore`. The crate owns provider health, capacity/history/analytics, terminal/request/error telemetry and bounded encrypted capture capabilities. It owns no credentials, inference, routing authority, scheduler, native executable or additional paid ledger. The controller retains workspace/lock integration and real Worker acceptance.

Contract v2 separates isolate-owned coordination data from every request's store and I/O host. Retain only `ObservabilityState::default()` per isolate. Construct a fresh `ObservabilityRuntime::with_state(request_store, request_host, state.clone())` for every request; `shared_state()` returns its data-only coordination handle. `ObservabilityRuntime::clone` is for the same request only. Queues contain observation metadata and completion receipts, never a store, host or I/O future. Each producer remains in its own request's driven future; coalescers cannot poll another request's I/O. Dropping a producer fails and releases its receipt, and completed requests are not retained. The event owner must still drain admitted durable writes and the fixed active probe through their actual termination.

The health unit implements source observations and projection, arrival-ordered isolate coalescing, heartbeat throttling, current-Claude revision fences and exact paid-body classification. `observe_provider` returns an observational write result and never an error that could change routing. `provider_health` returns actual durable rows and explicit read failures; public passive projections handle their source-specific unknown fallback separately.

`HealthTarget` carries the provider identity and exact source revision checks. Codex uses its real account identifier; ordinary providers use `default`; Claude uses its accepted `account:cohort:evidence_generation` identity and current-binding checks. Provider correlation values retain the source 256 UTF-16-unit/control-character bound. `paid_health` borrows already cloned, bounded body evidence, requires completeness before credit proof and does not consume the deliverable response. Full finite m12 provider/Codex/analytics/capture bindings and actual host crypto/transport acceptance remain in progress after this first unit.

All compiles run on immutable VPS snapshots under the shared tooling lock. Scoped native tests, strict clippy, formatting and wasm32 portability are required. Source-shaped keys, absolute expiry, typed U64 counters and source retention/race fixtures remain part of the completed-module gate. No unbound capability returns a successful placeholder.
