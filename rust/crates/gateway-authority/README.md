# Gateway authority

This crate ports the domain transitions extracted from source e706343d4a5f11890e39ab3599bdc04e154b1fba. The shared gateway-core AuthorityStore contract requires strong reads and one atomic durable commit of every checked revision and mutation. A successful store commit includes the platform durability barrier. A CAS conflict discards the candidate and rereads the complete decision; provider I/O and streams never enter a transaction.

The platform supplies TokenSource with unpredictable unique owner/probe/revision tokens. Record revisions remain opaque. Per-record schema versions and absolute expiry are validated; malformed or unavailable state fails closed. Separate records hold active coordination, outstanding indexes and retained history. The crate imposes no whole-history snapshot cap, eviction policy, timer, cron or alarm.

The routing module owns the global active subscription, selected-cohort proof, independent quota classes, current credential/generation fences, narrow learned model entitlement and bounded probe leases. Empty pools, unknown/model errors and held leases do not become authoritative pool exhaustion. Quota-only proof permits banked-reset evaluation; mixed quota/current-invalid proof permits ordinary paid continuation. Proof is re-evaluated against the current clock and exact stored revisions at use time. Direct paid models and disabled Codex retain their separate existing routing path.

The quota module keeps API-key dispatch charging separate from kernel semantic settlement. One ApiReservation survives every retry/provider hop. The runtime resolves a deferred reservation before actual provider dispatch, calls dispatch_api_key once per attempt, and marks transport intent immediately before fetch. A known pretransport cancellation can compensate; client cancellation after transport cannot refund it. Kernel terminal intent is durable, idempotent, independently renewed and settles only its original window. The source default kernel window is seven days.

The paid module retains one PaidAttemptId for each provider hop under the original RequestId. Existing pending attempts are returned as PaidAdmission::Existing so an integration cannot mistake ambiguous retained intent for permission to issue another paid request. Each new attempt persists dispatch intent, reserves integer exposure under the current key policy and versions its reconciliation gate before transport. Semantic terminal, correlated provider billing and delivery remain independent. Metered settlement requires exact upstream request id; Surplus settlement requires its exact reservation and preserves authoritative buyer microcredits. Actual spend can exceed reserved exposure and remains recorded. Pending/unresolved exposure is never refunded because of timeout or client cancellation.

The reset module accepts complete typed observations from the authenticated approved native provider boundary; it does not create provider authority or perform redemption. Shadow selection, live arming, account/window deduplication, owner leases, monotonic fences, per-account UTC-day budget and final submit renewal remain separate steps. Submitted/unknown recovery is lookup-only even when live policy is disabled. Ordinary overage fallback holds a scoped account/class lease without electing a different global active account, and the per-account allow setting is a hard gate. A stale verified reset cannot clear a newer quota generation; its explicit bounded recovery path cannot consume another credit.

API and kernel rows expire at their original window reset plus seven days. Paid request rows expire at creation plus 365 days and paid windows at reset plus 365 days; rewrites do not refresh those deadlines. Paid rollups, unresolved indexes, reset redemption/day records and owner decisions have no invented TTL. Event owners call due_paid and reconciliation lease methods; no periodic work is introduced.

Tests use a deterministic transactional fixture that enforces compare-and-set, logical expiry, checked mutations and unique writes, including actual thread races. They prove domain transitions only. They do not prove Workers SQLite persistence, native ownership, migration, hosted delivery, production data adoption or live inference. Those acceptance surfaces remain with their assigned runtime, native and delivery modules.

Public policy and pool types are shared with gateway-admin/native through this crate's key helpers. All key helpers use the controller's v3 shared TupleKey/ScalarKeyPart codec; the provisional JSON-array convention is retired with no compatibility fallback. Workspace membership and Cargo.lock are single-writer controller responsibilities. Rust compilation and formatting run on the VPS build lane, never implicitly on this Mac or during application startup.
