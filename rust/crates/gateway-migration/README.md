# Offline state adoption

This library accepts a private full logical capture with explicit original revision and absolute expiry on every row. It does not open a Bun/Deno database, read credentials, refresh tokens or activate a new owner. Ordinary profile NDJSON has no expiry metadata and is not a complete production-state capture. The existing target owner must stop source and target writers and withhold ordinary target traffic until adoption completes; a library over `AuthorityStore` cannot prove those OS conditions or fence arbitrary uncoordinated new-key writers.

`prepare(&PrivateCapture, &SourceDateHost)` validates the codec, full schema inventory and coupled indexes; `adopt_empty(&same_query_store, &prepared)` performs one atomic transition with absent-key checks and persistent inverse metadata. No existing target is overwritten. The target must be the actual common authority used by auth/admin/admission, not an independently live account ledger. Native current credential/publication ownership and proof capabilities are not imported from snapshots.

`export_latest(&quiesced_store, now)` reads current state, preserves post-adoption writes and deletions, inverts source/runtime schema differences and revalidates the complete latest source/index inventory. It never reads a stale backup. Identity rows do not duplicate historical provider/session secrets in sidecars. Original source-only fields are retained only for reviewed non-secret transforms. Keep private export artifacts and their hashes in the task's private evidence custody; never return them through an ordinary admin response or log them from a live service. See `TRANSFORMS.md` for exact families and remaining owning-runtime schema dependencies.

On the prepared VPS, under the same compiler lock, two Cargo jobs, frozen dependency graph and denied-network fixture boundary, run `cargo run --locked -p gateway-migration --example offline-fixture` and capture stdout to a task-local JSON artifact. This command accepts no arguments, only includes `tests/fixtures/offline-source.json`, creates fresh isolated SQLite files, restarts the actual store, authenticates its synthetic key, performs an actual post-restart admission write, exports the latest source state into a new inverse destination and proves logical equality. It opens no pre-existing database and makes no provider request. Temporary SQLite fixture files are removed after settlement; the captured JSON is the reproducible forward/latest/inverse artifact. This is an offline runtime fixture, not a production conversion command or activation receipt.

Source Date normalization uses `gateway_admin_data::profile::SourceDateHost` for arbitrary source-accepted Date inputs; constructor-bound runtime/locale/timezone semantics are required. The retained UTC and America/New_York Bun 1.4.0 goldens demonstrate why a timezone or byte-collation guess is unsafe. The actual Worker host binding and full combined workerd/native/UI receipts remain with their owners.
